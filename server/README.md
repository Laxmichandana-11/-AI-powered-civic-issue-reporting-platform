# CiviQ – AI-Powered Civic Issue Reporting Platform

CiviQ is a full-stack MERN application that enables citizens to report civic issues such as potholes, garbage dumps, water leakage, broken streetlights, and more.

The platform uses AI to classify issues, detect duplicate reports, and help authorities prioritize and resolve problems efficiently.

## 🚀 Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- Google Maps API
- Gemini API (AI)
